*What happens here stays here.*

## Before you start

* You need a Chirper account. Create one with `/account register`.
* Your server admins can set a separate **Dark Web Posts** forum channel in the dashboard. If they don't, Dark Web posts are published to the regular **Chirper Posts** channel.

***

## How it's different

Dark Web posts work like [Internet posts](/features/internet), with a few changes.

| | Internet | Dark Web |
| - | - | - |
| **Look** | Regular Chirper post | Dark card with a `.onion` address |
| **Channel** | Chirper Posts | Dark Web Posts |
| **Replies** | <Icon icon="check" /> | <Icon icon="check" /> |
| **Likes** | <Icon icon="check" /> | <Icon icon="check" /> |
| **Reposts** | <Icon icon="check" /> | <Icon icon="xmark" /> |
| **Bookmarks** | <Icon icon="check" /> | Not in Discord |
| **Polls** | <Icon icon="check" /> | <Icon icon="xmark" /> |
| **Anonymous posting** | <Icon icon="check" /> | <Icon icon="check" /> |
| **Badges** | Shown | Hidden |
| **On your profile** | Shown | Hidden |

<Tip>
  Post as **@anonymous** to keep your identity hidden. Server staff can still see who made an anonymous post, so they can moderate it if needed.
</Tip>

## Making a Dark Web post

<Tabs>
  <Tab title="Discord">
    <Steps>
      <Step title="Run /post">
        Run `/post` in your bot commands channel and choose **Dark Web**.
      </Step>

      <Step title="Fill in your post">
        Pick an **Account**, or **@anonymous** if your server allows it. Write your post in **Content** and optionally add an **Image**.
      </Step>

      <Step title="Submit">
        Click **Submit**. Your post is published to the Dark Web.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Chirper Web">
    <Steps>
      <Step title="Open the Dark Web">
        On [Chirper Web](https://chirper.app/app), click **Dark Web** in the sidebar.
      </Step>

      <Step title="Click Post">
        Click **Post** in the sidebar.
      </Step>

      <Step title="Write and post">
        Pick your account, write your post, and optionally add an image. Then publish it.
      </Step>
    </Steps>

</Tabs>

## Dark Web Marketplace

Buy and sell illegal goods away from the regular marketplace. Dark Web listings work like [Marketplace listings](/features/marketplace), with the Dark Web look.

<Tabs>
  <Tab title="Discord">
    Run `/market list` and choose **Dark Web**. Then fill in the item, price, description, and photo.
  </Tab>

  <Tab title="Chirper Web">
    Open **Dark Web**, click **Post**, and switch the composer to **Listing**. Then fill in the item, price, description, and photo.
  </Tab>
</Tabs>

Like Dark Web posts, Dark Web listings can't be bookmarked or listed anonymously.

## Dark Web Feed

Your server can share previews of new Dark Web posts in their own **Dark Web Feed** channel, separate from the Latest Feed. If no Dark Web Feed is set, previews go to the regular feed instead.

***

## For server admins

Set up the Dark Web in the **Forums** and **Feeds** sections of your server's [dashboard](https://chirper.app/dashboard).

| Setting | Section | What it does |
| - | - | - |
| **Dark Web Posts** | Forums | The forum channel where Dark Web posts are published. |
| **Dark Web Feed** | Feeds | The channel where previews of new Dark Web posts appear. |
| **Anonymous Posts** | Misc | Turn anonymous posting on or off for both Internet and Dark Web posts. |
