Add Chirper to your Discord server, create the roles and channels it needs, and configure it from the dashboard. By the end of this guide, Chirper is ready for your members to use.

***

## Before you start

* This guide is for **server admins**. If you just want to use Chirper, head to [Features](/features/overview).
* You need permission to manage your Discord server. You use it to invite Chirper, enable Community, and create roles and channels.
* Setup happens in Discord and on the [Chirper website](https://chirper.app), so keep both handy.

***

## Invite Chirper

<Steps>
  <Step title="Open the invite link">
    Add Chirper to your server with the [invite link](https://chirper.app/invite), or click **Invite Chirper** at the top of this page.
  </Step>

  <Step title="Authorize Chirper">
    Pick your server under **Add to server**, click **Continue**, review the permissions Chirper requests, and click **Authorize**. You need the **Manage Server** permission in that server.
  </Step>

  <Step title="Check that Chirper joined">
    Return to your server and look for Chirper in the member list.
  </Step>
</Steps>

<Screenshot src="/images/getting-started/invite.png" alt="Discord's authorization screen for adding Chirper to a server">
  Adding Chirper to your server
</Screenshot>

***

## Enable Community

Chirper posts to a **forum channel**, and Discord only allows forum channels on servers with **Community** enabled.

<Steps>
  <Step title="Open Server Settings">
    In your Discord server, open **Server Settings**.
  </Step>

  <Step title="Enable Community">
    Go to **Enable Community** and complete Discord's setup steps.
  </Step>
</Steps>

<Note>
  Discord may change the location or wording of its settings as the platform is updated.
</Note>

***

## Create roles and channels

Create these before you configure Chirper. If you already have staff roles, you can use those instead of creating new ones.

| Role | What it's for |
| - | - |
| **Manager Role** | Lets members manage your server's Chirper settings. You need at least one. |
| **Moderator Role** | Lets members moderate Chirper posts, reports, and profiles. You need at least one. |

| Channel | Type | What it's for |
| - | - | - |
| **Audit Logs** | Text | Receives Chirper audit logs. |
| **Report Channel** | Text | Receives Chirper reports. |
| **Post Channel** | Forum | Where Chirper posts are published. |

<Warning>
  The Post Channel **must be a forum channel**. If you can't create one, make sure Community is enabled.
</Warning>

## Configure Chirper

<Steps>
  <Step title="Run /setup">
    In your bot commands channel, run `/setup`. Chirper replies with a **Dashboard** button that only you can see.

    <Screenshot src="/images/getting-started/setup-reply.png" alt="Chirper's reply to /setup with a Dashboard button" width={520}>
      Chirper's reply to `/setup`
    </Screenshot>
  </Step>

  <Step title="Open the dashboard">
    Click **Dashboard** to open your server's dashboard on the Chirper website. You land on the **Settings** tab, which is split into sections: **Roles**, **Logging**, **Forums**, **Feeds**, **Misc**, and **Apps**.

    <Screenshot src="/images/getting-started/dashboard-settings.png" alt="The Chirper dashboard Settings tab showing the Roles section">
      The dashboard's Settings tab
    </Screenshot>
  </Step>

  <Step title="Fill in each section">
    Work through each section using the settings below. You can leave the other settings, including **Apps**, as they are for now.
  </Step>

  <Step title="Save your changes">
    Click **Save changes** in the bar at the bottom of the page.
  </Step>
</Steps>

<AccordionGroup>
  <Accordion title="Roles" icon="user-shield">
    | Setting | What to select |
    | - | - |
    | **Manager Role** | The role or roles that can manage your server's Chirper settings. |
    | **Moderator Role** | The role or roles that can moderate Chirper posts, reports, and profiles. |

    You can select multiple roles for both.
  </Accordion>

  <Accordion title="Logging" icon="scroll">
    | Setting | What to select |
    | - | - |
    | **Audit Logs** | The channel you created for audit logs. |
    | **Report Channel** | The channel you created for reports. |
    | **Report Ping** | Optional. The role or roles to ping when a new report is submitted. |
  </Accordion>

  <Accordion title="Forums" icon="comments">
    | Setting | What to select |
    | - | - |
    | **Chirper Posts** | The forum channel you created for posts. |
  </Accordion>

  <Accordion title="Feeds" icon="rss">
    Additional feed options. You don't need to change anything here for a basic setup.
  </Accordion>

  <Accordion title="Misc" icon="sliders">
    | Setting | What to select |
    | - | - |
    | **Server Timezone** | Your server's timezone. Chirper uses it for timestamps on posts. |
  </Accordion>
</AccordionGroup>

These are the settings Chirper needs to run. You can come back to the dashboard at any time to set up other features.

***

## Send your first post

Check that everything works by posting from your bot commands channel.

<Steps>
  <Step title="Create an account">
    Run `/account register` to create your Chirper account in this server.
  </Step>

  <Step title="Post">
    Run `/post` and fill in your post. It appears in your Post Channel.
  </Step>
</Steps>

<Check>
  If your post shows up, Chirper is set up and ready for your community.
</Check>

***

## Troubleshooting

<AccordionGroup>
  <Accordion title="Chirper isn't in my member list">
    Make sure you picked the right server and finished Discord's authorization. If Chirper still isn't there, use the [invite link](https://chirper.app/invite) again.
  </Accordion>

  <Accordion title="My forum channel isn't listed under Chirper Posts">
    **Chirper Posts** only lists forum channels. Check that your Post Channel is a forum channel and that Community is enabled.
  </Accordion>

  <Accordion title="My post didn't show up">
    Open the dashboard and check that you clicked **Save changes** and that **Chirper Posts** is set to your forum channel.
  </Accordion>
</AccordionGroup>
