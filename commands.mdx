Chirper has a lot of commands, but you can start posting in seconds. Run `/help` in Discord at any time for a quick overview and useful links.

***

## Quick start

<Steps>
  <Step title="Create an account">
    Run `/account register` to create a Chirper account in the server.
  </Step>

  <Step title="Make a post">
    Run `/post`, choose **Internet Post**, and fill in your post. That's it!
  </Step>
</Steps>

***

## Commands

<AccordionGroup>
  <Accordion title="Posting" icon="pen-to-square" defaultOpen>
    | Command | What it does |
    | - | - |
    | `/post` | Publish a post. Choose **Internet Post**, **Dark Web**, or **Poll**. |
    | `/market list` | List an item on the marketplace. Choose **Internet Listing** or **Dark Web**. |
    | `/bookmarks` | Browse and manage your saved posts. |

    See [Internet](/features/internet), [Marketplace](/features/marketplace), and [Dark Web](/features/dark-web).
  </Accordion>

  <Accordion title="Accounts and profiles" icon="user">
    | Command | What it does |
    | - | - |
    | `/account register` | Create a new Chirper account. You can have up to 3 per server. |
    | `/account edit` | Edit one of your accounts. |
    | `/profile` | View a Chirper profile. Leave the handle empty to view your own. |
    | `/collaborator add` | Invite someone to post as one of your accounts. |
    | `/collaborator remove` | Remove a collaborator, or cancel a pending invite. |
    | `/notifications manage` | Choose which notifications you receive in DMs. |

    See [Account management](/account-management).
  </Accordion>

  <Accordion title="General" icon="circle-info">
    | Command | What it does |
    | - | - |
    | `/help` | Learn about Chirper and get useful links. |
    | `/ping` | Check Chirper's system status. |
  </Accordion>
</AccordionGroup>

## Server admin commands

<Note>
  These commands need the **Administrator** permission in Discord, or one of your server's Chirper **Manager Roles**.
</Note>

<AccordionGroup>
  <Accordion title="Setup" icon="gear">
    | Command | What it does |
    | - | - |
    | `/setup` | Open your server's Chirper dashboard to set up Chirper. |
    | `/dashboard` | Open your server's Chirper dashboard to configure roles and channels. |
    | `/support code` | Give Chirper support temporary access to edit your server's settings. |

    See [Getting started](/getting-started).
  </Accordion>

  <Accordion title="Accounts" icon="users-gear">
    | Command | What it does |
    | - | - |
    | `/account manage` | Manage any Chirper account in the server. |
    | `/account binding` | Manage role-bound accounts that anyone with a role can post as. |
    | `/verification binding` | Manage roles that automatically verify a member's first account. |
  </Accordion>

  <Accordion title="Server alerts" icon="bell">
    | Command | What it does |
    | - | - |
    | `/alert send` | Publish an official alert to your server's Chirper apps. Set a title, message, category, priority, and how long it lasts. |
    | `/alert list` | List active alerts. |
    | `/alert cancel` | Cancel an active alert. |

    Alerts show under **Server Alerts** on Chirper Web and Chirper Desktop. They last 60 minutes unless you set a duration.
  </Accordion>
</AccordionGroup>
